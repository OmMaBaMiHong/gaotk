# 焚诀会员本地配置验收计划

**目标：** 在隔离的本地中转站配置三档月卡，验证人民币计费、精选模型、订阅额度和零余额使用，不发布线上套餐。

**方案：** 使用现有分组、渠道定价、模型白名单和订阅 API。新建独立 PostgreSQL/Redis，真实中转站连接本地模拟上游；模拟只验证协议、路由和账务，不证明供应商可用或模型质量。保留充值人民币 1:1，把测试渠道售价和成本都配置为人民币/token。旧会员分组屏蔽分支不参与。

**已知范围：** 启笔 30 元，免费精选模型；成章 69 元、40 元共享额度，DeepSeek 当前 Flash、GLM-5.3-Flash；著作 99 元、70 元共享额度，累加国内旗舰候选。GPT/Claude 等待具体供应商型号与报价后配置。Hy3、Qwen3.5 不作为本轮最新模型推荐；用户已明确确认排除 Hy3、Qwen3.5，优先最新实惠模型。千问 3.8 不虚构为腾讯已支持。免费目录本地用最新 Qwen3.8 27B 名称验证流程，真实渠道接入另验。

**实现文件：** `scripts/membership_local.py`（启动模拟上游、种子配置与 API 验收），`.local-membership/`（本地凭证、日志、结果，加入 git 本地排除，不提交）。无需先修改核心业务代码。

## 后续 Skoob 联调边界

Skoob 目前按 group_id 同步会员权益。新月卡各自一个独立分组，不能把多个周期套餐共用分组后直接假设页面价格正确。先完成中转站验收，再验证 Skoob 本地兑换、权益识别、Key 选择、模型目录及调用。不会直接重指现有 9002 环境的生产账号。

## 成功标准

接口验证产出真实数据库用量记录；响应、用量、余额、币种及模型列表一致。若需要改核心代码，先记录具体失败用例与最小修正，再运行对应回归，不将模拟通过表述为生产已上线。

## 实测发现与修复

- 混合分组成本规则必须匹配 composite 平台。本地误用 openai/deepseek 平台时规则未命中，统计回退为默认价格；已修正配置并重跑验证，不能把回退结果当真实毛利。
- 订阅到期且缓存未命中时，数据库仅查有效订阅并返回未找到，旧逻辑将其当作计费故障 503。新增针对性回归后，最小修复为返回订阅无效 403，不计入服务熔断失败次数；真实数据库故障仍返回 503。
- 额外边界检查发现，同一付费分组额度耗尽后，该 Key 下免费模型也被分组额度挡住。此项尚未修复，不能承诺“付费额度耗尽仍无缝使用免费模型”；正式发布前需解决或明确独立免费入口。
- 全服务测试套件有既存编译错误（UpdateUserBalance、NewTokenRefreshService 参数变化），未修改无关测试。使用 go list 返回的全部生产源文件，单独运行新增回归与已有账务缓存测试通过；构建、完整本地 API 验收通过。
- graphify update . --no-viz 已执行，但工具仍因 62891 节点 HTML 大小限制失败，未宣称图谱刷新成功。

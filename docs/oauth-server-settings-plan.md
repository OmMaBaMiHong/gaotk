# OAuth 回调后台管理

用户授权更新 GaoTK 的 Sub2API，并将授权配置做成后台管理设置。服务器实际运行 0.2.1、提交 34f3057f9，与本次隔离工作树基线一致；不升级其他功能。

1. 增加独立管理设置接口与数据库配置，展示客户端 ID、密钥是否已配置、允许回调列表。客户端密钥继续由部署环境管理，不返回明文。初始回显现有环境回调，保存后立即生效，支持多个精确 HTTPS 地址；保留已有 localhost/loopback 开发回调行为，并严格解析 URL。
2. 授权入口和确认入口都读取同一设置。数据库读取失败时拒绝授权，避免回落到已撤销的地址。测试多个地址、旧环境兼容、空名单、非法 URL、运行时更新与读取失败。
3. 在管理后台“设置 → 安全”增加授权回调卡片，独立保存并明确反馈。构建前后端并核对真实浏览器显示。
4. 先备份线上数据库、部署配置和原镜像标识，再切换版本化镜像；保留原地址并添加 https://skoob.cc/api/v1/account/oauth/callback，验证正确地址能进入登录、未知地址仍被拒绝。未获用户登录态时不宣称完成账号授权闭环。

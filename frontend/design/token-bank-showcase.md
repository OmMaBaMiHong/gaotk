# Token 银行收益展示

用户已选定页面最顶部单行广播，右侧「收益榜」打开现有 BaseDialog；不做折叠卡片或新页面。

沿用 TokenBankView 的 card、btn、primary 与 gray/dark 色阶、text-sm 字号、gap-3 和 px-4 py-3 间距。喇叭使用现有 Icon 的线性图标规格；排行榜复用现有表格分隔线。移动端广播单行截断，收益榜按钮始终可见；暗色使用现有 dark token。

金额沿用页面 USD、最多 8 位小数。只展示接口提供的已入账收益及脱敏昵称，无模拟收益、提现入口、个人参与开关。全局关闭时完全隐藏，开启无记录时诚实显示空态。广播每 8 秒切换，支持暂停、悬停暂停与系统减少动态效果，页面隐藏时停止轮播和请求。每 60 秒刷新，卸载时取消请求并清理监听。
